# Slide Forge — AI 幻灯片锻造流水线

## Purpose

做一份好 PPT 最耗时的不是"打字"，而是**结构设计**和**把内容讲清楚**。多数人打开 PowerPoint
就对着空白页发呆，或者堆满文字变成"word 搬家"。本技能把这件事拆成一条可复用的流水线：

> **主题 → 大纲 → 逐页内容 + 演讲词 → 渲染成幻灯片**

一条指令驱动的"思考流程" + 一个零依赖的渲染脚本，让你 10 分钟产出 80 分的演示，再用剩余时间打磨到 95 分。

## I/O（一句话）

- **输入**：一个主题（如"AI 如何改变教育"），或一份 Markdown 大纲文件。
- **输出**：结构化大纲 → 逐页标题/要点/演讲词 → 一个可直接放映的 `HTML` 幻灯片文件（附 `-o` 指定路径）。

## Workflow

### Step 1 — 澄清需求，产出结构化大纲

先问清三件事（缺省时给出合理默认，不阻塞）：

1. **对象与场景**：讲给谁？路演 / 答辩 / 汇报 / 教学？
2. **时长**：几分钟？对应页数（经验值：1 分钟 ≈ 1 页）。
3. **形式**：重数据、重故事、还是重观点？

然后用下面的"大纲模板"产出大纲（写成 Markdown）：

```markdown
# 演示总标题

## 第 1 页标题
- 核心要点 1
- 核心要点 2
    - 支撑细节
> 演讲词：这一页我打算怎么讲，起承转合的一句话。

## 第 2 页标题
- ...
```

**大纲设计三原则**：
- 每页只讲**一个**观点（One Slide, One Idea）。
- 标题写成**结论句**而不是名词（"AI 让备课效率翻 3 倍" > "AI 在教育中的应用"）。
- 每页 3~5 个要点，每点一句话，细节留给演讲词。

### Step 2 — 逐页填充内容与演讲词

对大纲里每一页，补全两样东西：

1. **要点**：把观点拆成 3~5 个短句，动词开头，可量化就量化。
2. **演讲词**：用 `> ` 写 2~4 句"口语版"串词——这一页你想让对方记住什么、怎么过渡到下一页。

> 演讲词是"逐页可讲"的关键：它不是要点复读，而是**你上台真正会说的话**。

### Step 3 — 用脚本渲染成幻灯片

把大纲保存为 `.md` 文件，运行本技能附带的脚本：

```bash
python build_slides.py outline.md -o slides.html
```

可选参数：

| 参数 | 作用 | 默认 |
| --- | --- | --- |
| `-o / --output` | 输出 HTML 路径 | 与大纲同名 `.html` |
| `--title` | 覆盖演示标题 | 取大纲第一个 `# ` |
| `--theme light\|dark` | 配色主题 | `light` |

脚本零第三方依赖，只用到 Python 标准库。生成的 HTML 单文件即可放映：

- `→ / 空格` 下一页，`←` 上一页，`Home` 回封面
- `S` 键显示/隐藏**演讲词**（演讲者视图）
- `F` 键全屏
- `Ctrl+P` 打印 → 每页一页 PDF

### Step 4 — 自检与迭代

放映一遍，对照检查清单：

- [ ] 每页是否只有一个观点？
- [ ] 标题是不是"结论句"？
- [ ] 有没有一页文字超过 60 字（说明要点没提炼）？
- [ ] 演讲词能不能照着念就自然？
- [ ] 前后页是否有过渡（承上启下）？

按需改大纲 → 重新运行脚本，几秒出 v2。

## Edge Cases（边界情况）

- **空大纲 / 没有 `##` 标题**：脚本会警告"没有解析出任何页面"。此时应检查是否用了 `## ` 定义每一页（而不是全靠 `# `）。
- **页面文字过多**：脚本不截断内容，但文字过多会挤压版面。规则：每页 ≤ 60 字，超了就拆页或下沉到演讲词。
- **演讲词不显示**：演讲词用 `> ` 前缀写在对应页下方，且放映时需按 `S` 键。打印/导出 PDF 默认不含演讲词（演讲稿另存为 `.md` 即可）。
- **图片引用**：用标准 `![说明](相对/绝对路径)` 或外链 URL。离线放映时图片请用相对路径并保证路径可访问；缺图不影响文字渲染。
- **代码块**：用 ```` ```lang ```` 包裹，脚本会自动转成带语言标签的等宽代码块。
- **特殊字符**：`<`、`&` 等会被正确转义，直接写即可，无需手动处理。
- **Windows 编码**：脚本以 `utf-8` 读写，大纲请保存为 UTF-8（记事本默认即可）。

## Examples

### 例 1：主题直接生成

> 用户："帮我做一份 5 页的 AI 科普演示，讲给完全不懂技术的人。"

1. 按 Step 1 产出大纲（5 页 + 封面）。
2. 按 Step 2 填要点与演讲词。
3. 保存 `ai-intro.md`，运行 `python build_slides.py ai-intro.md`。
4. 得到 `ai-intro.html`，按空格即可放映。

### 例 2：已有大纲直接渲染

> 用户："我有个大纲 `plan.md`，帮我做成幻灯片。"

直接运行 `python build_slides.py plan.md --theme dark -o deck.html`，几秒出片。

完整可运行的示例见 `examples/sample-outline.md`（可立即拿去渲染体验）。
