# Slide Forge 可复用 Prompt 模板（按需加载）

> 直接复制使用；`{...}` 为占位符，替换成你的实际内容。

## P1 · 主题 → 大纲

```
你是资深演示教练。请为下面这个主题设计一份幻灯片大纲。
主题：{你的主题}
对象：{讲给谁}   时长：{N 分钟}   形式：{重数据/重故事/重观点}

要求：
1. 共 {页数} 页（不含封面），按「问题→洞察→方案→证据→行动」叙事弧线组织。
2. 每页标题必须是"结论句"（不是名词）。
3. 每页 3~5 个要点，每条一句话。
4. 用下面的 Markdown 格式输出，不要多余解释：

# {演示总标题}

## {第1页结论式标题}
- 要点
- 要点
> 演讲词：……

## {第2页结论式标题}
...
```

## P2 · 大纲 → 逐页内容 + 演讲词

```
下面是一份演示大纲。请为每一页补全「要点」和「演讲词」。

{粘贴大纲}

要求：
1. 每页要点 3~5 条，动词开头，可量化就量化，单页正文 ≤ 60 字。
2. 演讲词写 2~4 句口语串词：这一页想让对方记住什么 + 如何过渡到下一页。
3. 保持 Markdown 格式（要点用 -，演讲词用 > ）。
```

## P3 · 精简一页（文字太多时）

```
这一页幻灯片要点太多/太长，请精简：

{粘贴该页内容}

要求：压缩到 3~5 个要点、每点 ≤ 20 字，标题改成结论句，多余细节移到演讲词（用 > 标注）。
```

## P4 · 演讲稿生成（把演讲词连成完整稿）

```
请把我的幻灯片逐页演讲词，连成一篇 {N 分钟} 的完整演讲稿。
要求：口语化、有过渡、语气自然；每页之间用「（翻页）」标记分隔。

{粘贴含 > 演讲词的大纲}
```

## P5 · 迭代反馈（放映后优化）

```
这是我做好的幻灯片大纲，请以挑剔的评审视角给出 5 条改进建议，按优先级排序：

{粘贴大纲}

评估维度：结构是否清晰？每页是否只有一个观点？标题是不是结论句？
演讲词能不能照着念？有没有更适合的叙事顺序？
```
