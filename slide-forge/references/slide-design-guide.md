# Slide Forge 设计规范（按需加载）

> 目标是"80 分快、95 分稳"。这套规范既约束大纲，也约束 AI 生成内容时的口径。

## 1. 结构规范（最重要）

| 规则 | 说明 |
| --- | --- |
| 一页一个观点 | 每页只有一个核心结论，标题即结论。 |
| 结论式标题 | 标题写"结果/判断"，不写名词。例：`AI 让备课效率翻 3 倍`，而非 `AI 与教育`。 |
| 3~5 个要点 | 每页要点 3~5 条，每条一句话（≤ 20 字）。细节放演讲词。 |
| 总量控制 | 单页正文字数 ≤ 60 字，超过就拆页。 |

## 2. 叙事弧线（经典 7 页骨架）

适合路演 / 答辩 / 汇报的通用结构，直接套用：

1. **封面** — 标题 + 一句话价值主张
2. **问题** — 现状痛点，制造"这确实是个问题"的共鸣
3. **洞察** — 为什么现在/为什么是我能解决
4. **方案** — 核心解法（1~2 页，讲清 how）
5. **证据** — 数据 / 案例 / 对比，证明有效
6. **竞争 / 壁垒** — 差异化或可持续性
7. **行动号召** — 结尾：要什么 / 下一步是什么

## 3. 要点写法

- **动词开头**：`把翻译成本降低 60%` 优于 `翻译成本降低`。
- **可量化就量化**：数字比形容词有力。
- **平行结构**：同页要点保持同一句式（都是"动词+名词"或都是"名词+数字"）。
- **删除"的/了/我们/大家"**：口语文案放演讲词，不放要点。

## 4. 演讲词写法（`> ` 前缀）

- 每页 2~4 句，是你**上台会说的话**，不是要点复读。
- 句式：`这一页我想让你记住 X` + `具体展开 1 句话` + `过渡到下一页`。
- 结尾页的演讲词要明确"行动号召"。

## 5. 视觉规范（脚本内置，无需手动调）

- 封面：深色渐变 + 白色大字；内容页：浅色卡片 + 深色正文。
- 主色 `#3b5bdb`（靛蓝），强调色 `#e8590c`（橙）用于勾边、进度条、演讲词标签。
- 字体栈：`Segoe UI / PingFang SC / Microsoft YaHei`，中文优先可读性。
- 支持 `--theme dark` 切换深色主题（适合投屏暗环境）。

## 6. 常见错误与纠正

| 反例 | 问题 | 纠正 |
| --- | --- | --- |
| 标题`市场分析` | 名词，无观点 | `下沉市场是下一增长极` |
| 一页 12 个 bullet | 要点没提炼 | 拆成 2~3 页，细节进演讲词 |
| 演讲词=要点复制 | 无增量信息 | 写"为什么"和"怎么过渡" |
| 满屏段落 | 不是幻灯片是文档 | 段落转 bullet，长句断成短句 |
